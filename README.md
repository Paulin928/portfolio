# 🌐 Portfolio

Portfolio personnel avec dashboard administrateur : suivi des visiteurs (IP, pays, date) et système de messages.

## 🛠 Stack technique

- **Backend** : Python + FastAPI + SQLAlchemy + Pydantic + PostgreSQL
- **Frontend** : React + TypeScript + Vite + Tailwind CSS v4
- **Base de données** : PostgreSQL 16 (via Docker)
